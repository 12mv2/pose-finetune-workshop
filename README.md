# Fine-tuning RTMPose for Gait Analysis

This repository is an outline for a planned workshop on fine-tuning the RTMPose‑S model with a small custom dataset of running videos. It currently contains this README and a license; the workshop scripts and setup instructions are not yet included.

Planned materials cover extracting and labeling frames, configuring MMPose for training, running inference, visualizing pose keypoints, and setting up a local or RunPod GPU environment.
